# Política de seguridad

SPECTRA Shop es un laboratorio académico. Las pruebas solo están autorizadas contra entornos locales o recursos propios expresamente aprobados.

No incluya en issues, commits o reportes públicos contraseñas, tokens, cookies, claves AWS, datos personales ni detalles explotables de un entorno activo. Use datos sintéticos.

Los hallazgos deben registrar requisito, amenaza, riesgo, control, prueba, evidencia reproducible y estado de corrección. No se declara un control como verificado sin ejecución real.
